# Colorful-dictionary 仕様書

> シリーズ全体の仕様書: [ColorfulTalk](https://github.com/ukagaka-irono/ColorfulTalk)（`docs/spec/dictionary.md` と同じ内容）

ColorfulYomi が使う、読み・アクセント付きの辞書と、その作成ツールです。

## ファイル

| ファイル | 内容 |
|---|---|
| `colorful_talk.dic` | 辞書（バイナリ、26,297,880 バイト、481,977 語・396,026 表層形） |

辞書ファイルはリポジトリには入れず、GitHub の[リリース](https://github.com/ukagaka-irono/Colorful-dictionary/releases/tag/v1)に添付します（版 1 の SHA-256: `9926d6cbfba5d3efb0208853033ccc05d5b9c87fb8ef9b11e43c93e972ee724d`）。

## 辞書の作り方

```bash
python tools/build_dic.py --fetch -o colorful_talk.dic
```

`--fetch` は上の固定したコミットから元データを `naist-jdic/` に取得し、SHA-256 を確かめます（約 66MB）。
手元の元データを使うときは `--src DIR` を指定します。同じ元データからは毎回同じ辞書ができます。

## 形式（版 1）

数値はすべてリトルエンディアン。ヘッダの後に各部分がこの順で並び、それぞれ 4 バイト境界に揃えます。

### ヘッダ（64 バイト）

| 位置 | 型 | 内容 |
|---|---|---|
| 0 | char[8] | マジック `CTDIC\0\0\0` |
| 8 | u32 | 版（1） |
| 12 | u32 | 表層形の数 |
| 16 | u32 | 語の数 |
| 20 | u16 | 連接表の行数（前の語の右文脈 ID の数） |
| 22 | u16 | 連接表の列数（後の語の左文脈 ID の数） |
| 24 | u32 | 文字種の区間の数 |
| 28 | u32 | 文字種の数（32 まで） |
| 32 | u32 | 未知語定義の数 |
| 36 | u32 | 品詞の数 |
| 40 | u32 | 文字列プールの大きさ（バイト） |
| 44 | — | 0 で埋める |

### 各部分

| 部分 | 1 件の大きさ | 内容 |
|---|---|---|
| 表層形の表 | 12 | u32 文字列の位置、u32 最初の語の番号、u16 語の数、u16 表層形のバイト数。表層形の UTF-8 バイト順 |
| 語の表 | 20 | u16 左文脈 ID、u16 右文脈 ID、i16 コスト、u16 品詞の番号、u32 発音の位置、u32 アクセントの位置、u32 結合規則の位置。同じ表層形の語はコスト順 |
| 連接表 | 2 | i16。`[前の語の右文脈 ID × 列数 + 後の語の左文脈 ID]` |
| 文字種の区間 | 16 | u32 始まり、u32 終わり（コードポイント）、u16 主な文字種、u16 0、u32 当てはまる文字種のビット。重ならず昇順 |
| 文字種の定義 | 8 | u8 常に未知語を作るか、u8 同じ文字種をまとめるか、u8 最大の長さ、u8 0、u32 名前の位置 |
| 未知語定義 | 12 | u16 文字種、u16 左文脈 ID、u16 右文脈 ID、i16 コスト、u16 品詞の番号、u16 0 |
| 品詞の表 | 4 | u32 文字列の位置（"品詞,細分類1,細分類2,細分類3,活用型,活用形"） |
| 文字列プール | — | NUL 終端の UTF-8 文字列。位置 0 は空文字列。同じ文字列は 1 つにまとめる |

- 発音はカタカナ（長音は「ー」、無声化の印「’」を含むことがある）。複数のアクセント句からなる語は `:` で区切る
- アクセントは `核/モーラ数`（例 `1/2`）。複数句の語は `2/5:4/6` のように `:` で区切る
- 結合規則は元データのまま（`C1`〜`C5`、`P1` `P2`、`名詞%F2@1/動詞%F1` など）。意味は ColorfulYomi の仕様書を参照
- 前方一致の検索は、表層形の表を二分探索し、キーを 1 文字ずつ伸ばしながら「キーで始まる表層形がある間」続けます

## ユーザー辞書

辞書ファイルは変えずに、ColorfulYomi の `cy_add_user_dic()` で CSV（UTF-8）を追加します。書き方は ColorfulYomi の仕様書を参照してください。
