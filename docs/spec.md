# Colorful-dictionary 仕様書

> 状態: 案（設計中）。シリーズ全体の仕様書: [ColorfulTalk](https://github.com/ukagaka-irono/ColorfulTalk)（`docs/spec/dictionary.md` と同じ内容）

ColorfulYomi が使う、読み・アクセント付きの辞書と、その作成ツールです。

## 元データとライセンス

| 項目 | 内容 |
|---|---|
| 元データ | Open JTalk に同梱の mecab-naist-jdic（表層形・品詞・読み・発音・アクセント型・アクセント結合規則・連接コスト） |
| 元データのライセンス | BSD 3-Clause（NAIST、名古屋工業大学 HTS Working Group） |
| 辞書ファイルのライセンス | 元データと同じ BSD 3-Clause。配布物に `NOTICE`（両者の著作権表示と条件の全文）を同梱する |
| 作成ツールのライセンス | MIT |

ColorfulYomi やエンジン本体は MIT のままです。辞書を同梱して配布するときは `NOTICE` も一緒に配布してください。

## ファイル

| ファイル | 内容 |
|---|---|
| `colorful_talk.dic` | 辞書（バイナリ、約 26MB） |
| `NOTICE` | 元データの著作権表示とライセンス |
| `tools/build_dic.py` | 元データから辞書を作るツール |

辞書ファイルはリポジトリには入れず、GitHub のリリースに添付します。

## 辞書の作り方

```bash
python tools/build_dic.py --fetch -o colorful_talk.dic
```

`--fetch` は Open JTalk の固定したコミットから元データを取得します。手元の元データを使うときは `--src DIR` を指定します。

## 形式（版 1）

数値はリトルエンディアン。

| 部分 | 内容 |
|---|---|
| ヘッダ（64 バイト） | マジック `CTDIC\0\0\0`、版、表層形の数、語の数、連接表の行数・列数、文字種の区間の数、文字種の数、未知語定義の数、文字列プールの大きさ |
| 表層形の表 | 表層形ごとに（文字列プールの位置、最初の語の番号、語の数）。表層形の UTF-8 バイト順に並ぶ |
| 語の表 | 左文脈 ID、右文脈 ID、コスト、品詞、品詞の細分類フラグ、アクセント型、モーラ数、発音の位置、結合規則の位置 |
| 連接表 | 左文脈 × 右文脈の int16 |
| 文字種の区間 | コードポイントの範囲と文字種 |
| 文字種の定義 | 未知語の扱い（常に未知語として扱うか、同じ文字種をまとめるか、最大の長さ） |
| 未知語定義 | 文字種ごとの品詞・文脈 ID・コスト |
| 文字列プール | 表層形・発音（カタカナ）・結合規則（ASCII）の UTF-8 文字列 |

検索は表層形の表を二分探索で引きます（前方一致は先頭文字ごとの範囲から）。

## ユーザー辞書（案）

CSV（UTF-8）で登録します。

```
表層形,読み（カタカナ）,アクセント型,品詞
ColorfulTalk,カラフルトーク,5,名詞
```
